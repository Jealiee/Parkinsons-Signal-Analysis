# Decision-Making in Parkinson's Disease

This repository contains the code developed for the analysis of behavioral, EMG, and subthalamic nucleus (STN) local field potential (LFP) recordings collected during a reinforcement learning decision-making task performed by Parkinson's disease patients.

The project was completed as part of the Neural Prosthesis course at the University of Pisa (2026).

The analysis includes:

* behavioral data parsing and processing,
* synchronization of behavioral events with events enconded in EMG and LFP recordings,
* reaction time extraction,
* behavioral statistical analysis,
* event-related potential (ERP) analysis,
* beta-band power analysis of STN recordings.

Due to patient privacy regulations, the original recordings and extracted data are **not included** in this repository.

In the repository you can find a project_presentation.pdf file, describing the methodology and results.
